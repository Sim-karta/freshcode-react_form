# React FSD

Пустой каркас приложения на React и Vite с архитектурой Feature-Sliced Design.

## Структура `src`

- `app` — точка входа приложения, его корневой компонент, стили и провайдеры.
- `pages` — страницы приложения.
- `widgets` — крупные самостоятельные блоки интерфейса.
- `features` — пользовательские действия и сценарии.
- `entities` — бизнес-сущности.
- `shared` — переиспользуемая инфраструктура и UI:
  - `api` — работа с API;
  - `assets` — общие статические ресурсы;
  - `config` — общая конфигурация;
  - `lib` — общие утилиты и библиотеки;
  - `ui` — базовые UI-компоненты.

Пустые слои и сегменты содержат `.gitkeep`, чтобы оставаться в системе контроля версий.

## Команды

- `npm run dev` — запуск dev-сервера;
- `npm run build` — production-сборка;
- `npm run lint` — проверка ESLint;
- `npm run preview` — просмотр production-сборки.
